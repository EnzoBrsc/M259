# Exemple exclusivement fictif

`candidats_fictifs.csv` contient trois joueurs et des historiques entièrement
inventés, année 2099. Il illustre seulement le format des huit entrées historiques
du contrat réel de Luca. Ce ne sont ni des candidats réels, ni des performances
sportives, ni des résultats du projet. Aucun classement de cet exemple ne doit
être présenté comme un résultat de l'étude.

Les cellules numériques vides seront imputées par la pipeline entraînée.
Pour vérifier les données réelles, utiliser le mode « Dataset historique de Luca
(test) » et importer `data/processed/ballon_or.csv` ; seules 2022–2025 sont évaluées.
